## 4. Issues Identified

### Bug #1 — Teacher Designations All "Lecturer"
**Root cause:** `r.designation` is `NULL` in every teacher row. The survey answers have no `Designation` field either. The `designation` column was never populated during Google Sheets import.

**Fix:** Either (a) mark this chart as "Data pending — field not collected" OR (b) attempt parsing from the `Department` or a cross-reference to the profiles table.

---

### Bug #2 — Misrouted "Student Pre" Rows Have Teacher Form Keys
When the pipeline routes misrouted rows (`is_misrouted=true`) back to `participant_type=student`, these rows still carry **teacher form answer keys** (e.g., `Q1. On average, how many hours per week do you spend on manual lesson planning...`). The student obstacles aggregation (`Q2. What is your biggest obstacle...`) finds nothing and adds zero — slightly undercounting obstacles for those 58 misrouted student-pre rows.

**Fix:** Add an `is_misrouted` exclusion guard in the `studentPre` aggregation filters.

---

### Bug #3 — Timeline Velocity Is Meaningless
All 2,308 rows were bulk-imported at a single timestamp. Week-by-week velocity cannot be reconstructed from `submitted_at`.

**Fix:** Add a `google_timestamp` column during import (preserve the original Google Form `Timestamp` answer field). Then compute real weekly buckets from that.

---

### Issue #4 — `future_adoption_intent` Showed False "ALL ZERO" in Checker
This was a false-positive in the test script — the data structure is nested `{students: [...], faculty: [...]}` not a flat array, so the zero-checker returned wrong. The actual data is correct (52.4% / 49%).

---

### Issue #5 — AI Familiarity Shift Has Wrong Post Question
The `postFamDist` is computed from `Q5. How noticeably did your quiz/assignment performance...` — which is a Likert improvement scale, **not an AI familiarity rating**. So the "Advanced User: 59.5% Post" figure is actually "those who rated concept improvement ≥ 4" — **not true AI competency**.

**Fix:** The post-survey has no direct AI familiarity self-rating question. Either use `Q6` (reliability) or keep the Likert as a proxy but relabel it as "Concept Improvement" not "AI Competency Level."

---

### Issue #6 — Student Obstacles Overcounts (Misrouted Rows)
58 rows with `is_misrouted=true` and `survey_phase='pre'` are counted in `studentPre`. These rows have teacher-form answer keys, so the Q2 obstacle lookup returns empty for them — they don't distort the percentages, but they inflate `sPreTotal` from 1,273 to 1,331 real student forms, **diluting** every obstacle percentage by ~4.6%.
